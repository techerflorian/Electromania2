** Framework PDO MVC BOOTSTRAP5 V5.0 **

- le controleur principal est : "www/index.php"
- toutes les url sont de la forme : index.php?m=<controleur>&a=<action>
- les controleurs secondaires sont dans "application/module/<module>"
- les requetes SQL sont dans le dossier "application/table"

|-- application : les fichiers propres à l'application web

   |-- _config : 
      |-- config.php : fichier de configuration inclus dans le controleur principal (index.php)

   |-- _gabarit : fichiers utilisés pour les gabarits (modèles de pages)
      |-- gabarit.php : gabarit par défaut
      |-- inc_entete.php : entête de page (bandeau supérieur)
      |-- inc_head.php : entête HTML (charge les fichiers css et js)
      |-- inc_menu.php : barre de navigation principale (en partie généré)
      |-- inc_pied.php : pied de page   

   |-- module : dossier contenant les modules (ou contrôleurs secondaires)
      |-- _default : module pour déclencher des actions de prépartion du projet, database, générateur, log.
      |-- _generateur : permet de générer un module "CRUD" et une class Table pour chaque tables de la BDD. 
      |-- <module> : dossier d'un module. Pour un module de type CRUD, le nom du module correspond à une table et les fichiers sont :
         |-- Ctr_<table>.php : Controleur secondaire 
         |-- vue_<table>_edit.php : formulaire d'édition/création
         |-- vue_<table>_index.php : affiche la liste des enregistrements
         |-- vue_<table>_show.php : affiche un enregistrement

   |-- table : dossier des requêtes SQL. Contient toutes les classes héritées de Table.class.php et toute classe accédant à la BDD

|-- document : cahier des charge, documentation, script sql...etc

|-- framework : dossier des fichiers internes au framework
   |-- Ctr_controleur.class.php : classe mère des controleurs   
   |-- fonction.php : fonctions utiles (autoload)
   |-- Table.class.php : classe mère des tables   
   |-- CsrfToken.class.php : classe pour gérer les token CSRF
   |-- EnvLoader.class.php : classe pour charger les variables d'environnements définies dans .env
   |-- ErrorHandler.class.php : classe pour gérer les erreurs
   |-- Logger.class.php : classe pour gérer les logs
   |-- I_crud.class.php : inteface pour les controleur CRUD
   |-- TraitUser.class.php : méthodes utiles pour authentification

|-- logs : dossier des fichiers de logs

|-- vendor : dossier des librairies externes

|-- www : racine du site web
   |-- _css : fichiers css   
   |-- _images : fichiers images
   |-- _js : fichiers javascript
   |-- index.php : controleur principal

|-- composer.json : gestion des librairies utilisées. Pour installer les librairies : "composer install"
|-- composer.lock : gestion des librairies
|-- .env : fichier des variables d'environnements
|-- .gitignore : fichiers à exclure des push
|-- framework_doc.txt : documentation du framework
|-- updates_notes.txt : historique des mises à jour.


** FICHIERS DU DOSSIER "framework" **

1. la classe Table
Classe générique pour faire des requêtes CRUD.
Cette classe sert de classe mère pour les classes représentants les tables de la base de données.

attributs :
	+ static PDO $link // connexion à la base de données
	+ string $table // nom de la table
	+ string $pk // nom du champ clé primaire
méthodes :
	+ __construct(string $table, string $pk)
	+ selectAll(): array //return tous les enregistrements
	+ select(int $id) : array //return 1 enregistrement
	+ getFields(): array //liste des champs de la table
	+ emptyRecord(): array //return return 1 enregistrement vide
	+ updateSql(array $data) : string //return la chaine sql pour une requete préparée update
	+ insertSql(array $data) : string //return la chaine sql pour une requete préparée insert
	+ save(array $data): int //enregistre en base de données 1 enregistrement, et retourne la valeur de sa clé primaire 	
	+ delete(int $id) //supprime un enregistrement
	+ static HTMLoptions(string $sql, string $pk, string $label, int $id) : string //balises option pour un select
    + static creer($file) : execute le script de création de la base de données
    + static dataset() : pour générer un dataset...
	

2. la classe Ctr_controleur
Classe mère pour les classes contrôleurs
attributs :
	+ string $module //nom du module
	+ string $action //nom de l'action
	+ string $gabarit //nom et chemin du fichier gabarit
	+ string $vue //nom et chemin du fichier vue
méthodes : 
	+ __construct($module, $action, $gabarit="gabarit.php")

3. L'interface I_crud 
Interface pour les classes controleurs qui implémente un CRUD.
	+ a_index //affiche tous les enregsitrements
	+ a_edit //affiche un formulaire d'édition/création d'un enregistrement
	+ a_save //enregiste en base de données les données du formulaire
	+ a_delete //supprime un enregistrement
